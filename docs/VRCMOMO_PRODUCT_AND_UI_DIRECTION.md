# VRCMomo: Product and UI Direction

> **VRCMomo — Stay close to your VRChat life.**
>
> 一个有完整工具能力、稳定发行节奏，并能和 VRCX 一起使用的移动端 VRChat Companion。

## 1. 为什么不只是“另一个 VRCM”

VRCM 仍然是本项目的重要上游：它持续维护 API、账号、好友、世界与图库等通用能力。VRCMomo 不应承诺在每一个接口页面上都比上游更快、更全，也不应简单地把上游的停更误判当作项目存在理由。

VRCMomo 的定位是：

- 以 VRCM 的成熟能力为基础，持续同步有价值的上游更新；
- 做一个**真正适合每天在手机上打开**的完整 VRChat Companion；
- 以稳定 APK / IPA、清晰更新说明和可验证构建作为基本承诺；
- 把“好友关系、状态变化、互动、照片与记忆”做成连续体验；
- 成为 VRCX 用户在移动端的自然延伸，而不是与 VRCX 争夺桌面端定位。

一句话：

> **VRCMomo 是面向移动端社交与日常使用的全功能 VRChat Companion，也是 VRCX 的移动搭档。**

## 2. 与 VRCM、VRCX 的关系

| 产品 | 最擅长的场景 | VRCMomo 的关系 |
| --- | --- | --- |
| VRCM（上游） | 通用移动功能、VRChat API 基础能力 | 作为上游基础：选择性同步、修复通用问题并尽量回馈上游。 |
| VRCX | 桌面端的高级管理、记录、批量操作与深度信息查看 | 作为桌面搭档：导入已有资料、提供移动提醒、在手机端继续关系与记忆。 |
| VRCMomo | 手机端的关系、提醒、互动、相册、清晰的日常入口 | 自己的主战场。 |

因此，VRCMomo 的“更完善”不应该是简单堆叠页面，而是让完整流程更自然：

```text
电脑上用 VRCX 整理资料
        ↓
VRCMomo 导入 / 同步可携带数据
        ↓
手机上看重要的人、收到提醒、发 Boop、浏览相册
        ↓
需要深度管理时回到 VRCX
```

## 3. 数据兼容：先做可靠的“导入”，再做可验证的“导出”

### 不做的事

- 不读取、不复制 VRCX 的账号 Cookie、Token 或登录数据库；
- 不直接写入 VRCX 的 SQLite 数据库；
- 不承诺未经 VRCX 支持的“任意数据双向同步”。

直接改 VRCX 数据库会让版本升级、数据库迁移、隐私与数据损坏风险全部落在用户身上，不适合作为移动应用的数据交换方式。

### 要做的事

1. **VRCX Importer（优先）**
   - 用户从 VRCX 导出的文件中选择导入；
   - 先显示预览和冲突处理，不静默覆盖；
   - 第一批支持：好友备注、收藏分组、可识别的关系标记；
   - 数据仅作为 VRCMomo 的本地扩展资料，VRChat 官方数据仍以 API 实时结果为准。

2. **Momo Archive（主格式）**
   - 使用带 `schemaVersion` 的 JSON 导出；
   - 用户拥有自己的好友备注、关系标签、Boop 偏好、相册收藏和本地记忆；
   - 以后新版本可迁移，且 Android 与 iOS 格式一致。

3. **VRCX-compatible Export（限制性支持）**
   - 只输出 VRCX 已有、可确认接受的格式；
   - 需要完整双向支持时，应为 VRCX 提交一个明确的导入/导出格式改进，而不是偷偷适配其内部数据库。

## 4. 产品优先级

### P0：每天打开时有价值

- 收藏好友上线 / 下线与 Boop 的通知；
- 明确、稳定的好友在线与所在世界信息；
- 重要的人优先于冗长列表；
- Android 与 iOS 的一致基础体验。

### P1：让关系可读

- 共同好友、关系网络、用户备注与收藏分组；
- 从 VRCX 导入已有的个人整理成果；
- 好友资料页里集中显示：状态、共同好友、互动和个人备注。

### P2：让记忆留下来

- VRChat Gallery 浏览；
- 收藏、时间线与“回忆”入口；
- 以后再考虑共同照片、世界记录或留言。

### P3：完整工具能力

- 保留并逐步完善上游 VRCM 的搜索、世界、通知、好友、图库等能力；
- 用稳定发布节奏把已完成能力交到用户手上。

## 5. UI 设计契约（v0.2 起）

**风格：** Warm Companion（温暖、克制、清楚），参考 ArkUI 的信息层级与可读性，不复制 HarmonyOS 的具体视觉资产。

**深度：** Moderate。先建立颜色、间距、圆角、卡片和导航规范；不为了“新 UI”制造不真实的活动数据或牺牲信息密度。

**首页唯一任务：** 让用户在几秒内知道“今天值得关心什么”，并能立即点进对应的人或互动。

### 主导航

```text
现在      朋友      回忆      我的
Now       Friends   Moments   You
```

- **现在**：收藏好友状态变化、最近 Boop、待处理通知、快捷搜索。
- **朋友**：在线 / 收藏 / 全部 / 搜索、共同好友与关系网络。
- **回忆**：Gallery、收藏照片、以后加入世界与互动时间线。
- **我的**：资料、通知偏好、VRCX 导入导出、隐私与设置。

原有的功能页不会被删除；迁移期间仍可从“朋友”和“我的”进入现有工具。
